# 🚀 Web Resume / Portfolio App

ยินดีต้อนรับสู่โปรเจกต์ **Web Resume / Projects Portfolio** ซึ่งเป็นเว็บแอปพลิเคชันสไตล์โมเดิร์นที่พัฒนาขึ้นมาเพื่อจัดแสดงผลงานโครงการ (Projects) และเกียรติบัตรต่างๆ (Certifications) ของคุณได้อย่างสวยงาม สะดวกรวดเร็ว และสามารถเข้าถึงได้ทุกที่ทุกเวลา

แอปพลิเคชันนี้มาพร้อมกับระบบจัดการข้อมูลในตัว (Interactive CMS) ทำให้คุณสามารถจัดระเบียบ เพิ่ม ลบ แก้ไข และสลับตำแหน่งผลงานได้โดยตรงผ่านหน้าเว็บ พร้อมระบบจัดเก็บข้อมูลทั้งแบบภายในเครื่องและบนระบบคลาวด์

---

## ✨ คุณสมบัติหลัก (Key Features)

*   **🗂️ Multi-Tab Display**: แยกหน้าการ์ดแสดงผลระหว่าง **โครงการ (Projects)** และ **เกียรติบัตร (Certifications)** ออกจากกันเพื่อความเป็นระเบียบเรียบร้อย พร้อมเอฟเฟกต์สลับหน้าอย่างลื่นไหล
*   **🔒 Password-Protected Edit Mode**: ปกป้องสิทธิ์การแก้ไขข้อมูลด้วยรหัสผ่านความปลอดภัยสูง (รหัสผ่านเริ่มต้น: `Earth-1148`) เพื่อเข้าสู่โหมดจัดการข้อมูล (CMS)
*   **✏️ Full CRUD Capability**:
    *   **เพิ่ม (Create)**: ฟอร์มป๊อปอัปสำหรับใส่รายละเอียดโครงการและเกียรติบัตร พร้อมรองรับการอัปโหลดไฟล์รูปภาพแปลงเป็น Base64
    *   **แก้ไข (Update)**: ปรับปรุงข้อมูล รูปภาพ ลิงก์เดโม ลิงก์ GitHub หรือรายละเอียดของโครงการ/เกียรติบัตรที่บันทึกไปแล้วได้ทันที
    *   **ลบ (Delete)**: ระบบยืนยันการลบข้อมูล (Confirmation Modal) เพื่อความปลอดภัย ป้องกันอุบัติเหตุการเผลอกดลบ
*   **🎛️ Drag & Drop Reordering**: ในโหมดแก้ไข (Unlock) ผู้ใช้สามารถใช้เมาส์ลากจัดเรียงอันดับผลงาน (Reorder) ได้อย่างอิสระตามความต้องการ
*   **🔄 Dual-Sync Data Layer (ระบบซิงก์ข้อมูลอัจฉริยะ)**:
    *   **Local Caching**: บันทึกข้อมูลลง `LocalStorage` ทันทีเพื่อความรวดเร็วในการเปิดดูครั้งถัดไป (Instant Loading)
    *   **Debounced Cloud Syncing**: ซิงก์ข้อมูลไปเก็บยัง Cloudflare Workers (`https://projects-certificate.earth7137.workers.dev`) ทุกๆ 1 วินาทีหลังจากพิมพ์หรือแก้ไขข้อมูลเสร็จ
    *   **Local Server Backup**: มีระบบ Backend Server ในตัว (Express) ที่สามารถรับและส่งข้อมูลมาบันทึกเป็นไฟล์ `data.json` ในเครื่องคอมพิวเตอร์ของคุณ

## 🛠️ โครงสร้างเทคโนโลยี (Tech Stack)

### Frontend (หน้าบ้าน)
*   **React 19** - ไลบรารีสำหรับสร้าง User Interface ยอดนิยม
*   **Vite 6** - บิลด์ทูล (Build Tool) ที่เร็วที่สุดสำหรับการทำโมเดิร์นเว็บแอป
*   **TypeScript** - เขียนโค้ดอย่างปลอดภัยและเป็นระเบียบด้วยระบบ Type Check
*   **Tailwind CSS v4** - เฟรมเวิร์ก CSS ยุคใหม่ที่ออกแบบมาเพื่อความเร็วและยืดหยุ่นสูง
*   **Motion (Framer Motion v12)** - สร้างอนิเมชันตอนสลับแท็บ ย้ายหน้าต่าง และการลากวางที่สวยงามและสมบูรณ์แบบ
*   **Lucide React** - ชุดไอคอนเวกเตอร์ที่สวยงามและมีความทันสมัย

### Backend (หลังบ้าน)
*   **Express & Node.js** - เว็บเซิร์ฟเวอร์ขนาดเล็กสำหรับให้บริการ API ในฝั่ง Local
*   **Tsx** - สำหรับรันไฟล์ TypeScript ฝั่งเซิร์ฟเวอร์โดยตรงโดยไม่ต้องแปลงไฟล์เป็น JS ก่อน
*   **data.json** - ฐานข้อมูลในรูปแบบไฟล์ JSON ของระบบเมื่อรันและบันทึกผ่านเซิร์ฟเวอร์แบบ Local

## 💻 วิธีการติดตั้งและการรันใช้งาน (Installation & Setup)

### 📌 ความต้องการของระบบ (Prerequisites)
เครื่องคอมพิวเตอร์ของคุณต้องติดตั้ง **Node.js** (แนะนำเวอร์ชัน 18 ขึ้นไป)

### ⚙️ ขั้นตอนการติดตั้ง (Installation Steps)

1.  **ดาวน์โหลด/โคลนคลังเก็บโค้ด** ลงมายังเครื่องคอมพิวเตอร์ของคุณ
2.  เปิดโปรแกรม Terminal หรือ Command Prompt ในโฟลเดอร์ของโปรเจกต์นี้
3.  ติดตั้ง Node Modules เสริมด้วยคำสั่ง:
    ```bash
    npm install
    ```
4.  ก๊อปปี้ไฟล์ `.env.example` แล้วเปลี่ยนชื่อเป็น `.env.local` จากนั้นระบุคีย์หากใช้งานฟีเจอร์ของ AI (หากรันผ่าน AI Studio ระบบจะแทรกให้อัตโนมัติ):
    ```bash
    GEMINI_API_KEY="ระบุคีย์ของคุณที่นี่"
    ```

## 🚀 วิธีการสั่งรันแอปพลิเคชัน (Running the Application)

มีคำสั่งหลักที่ใช้ควบคุมอยู่ 2 คำสั่ง (ตาม `package.json`):

### 1. การรัน Frontend (หน้าบ้าน)
เพื่อรันเว็บแอปพลิเคชันจำลองหน้าเว็บขึ้นมาใช้ในการแสดงผลและแก้ไข ให้ใช้คำสั่ง:
```bash
npm run dev
```
*   เมื่อรันสำเร็จ เว็บแอปพลิเคชันจะเปิดทำงานที่พอร์ต 3000: **[http://localhost:3000](http://localhost:3000)**

### 2. การรัน Local Backend Server (หลังบ้าน - ตัวเลือกเพิ่มเติม)
หากคุณต้องการเก็บบันทึกข้อมูลลงในรูปแบบไฟล์ JSON ภายในเครื่องของคุณ (`data.json`) แทนการส่งไปยังคลาวด์ ให้รันเซิร์ฟเวอร์หลังบ้านด้วยคำสั่ง:
```bash
npm run server
```
*   ระบบหลังบ้านจะรันสำเร็จที่พอร์ต 3001: **[http://localhost:3001](http://localhost:3001)**
*   *(หมายเหตุ: ใน [src/App.tsx](file:///c:/Users/earth/OneDrive/Desktop/All%20WEB/Web%20Resume/Web%20Resume/src/App.tsx#L13) หากต้องการสลับไปเชื่อมต่อกับพอร์ตในเครื่องตัวเอง ให้เปลี่ยนตัวแปร `WORKER_URL` จากลิงก์คลาวด์เป็น `'http://localhost:3001'`)*

## 🔒 ขั้นตอนการใช้งานโหมดแก้ไขและจัดการผลงาน (How to Edit Content)

1.  เปิดหน้าเว็บไปยัง **[http://localhost:3000](http://localhost:3000)**
2.  ที่มุมบนขวา ให้คลิกปุ่ม **"Edit" (มีรูปแม่กุญแจล็อกอยู่)**
3.  จะมีป๊อปอัปให้ยืนยันตัวตน ให้ระบุรหัสผ่านปลดล็อก: `Earth-1148` แล้วกด **Unlock**
4.  หน้าเว็บจะเปลี่ยนเป็นโหมดแก้ไขสำเร็จ:
    *   **ปุ่มเพิ่มข้อมูล (Add Project / Add Certification)** จะปรากฏขึ้นมาที่ส่วนหัวและด้านล่างสุดของรายการผลงานเมื่อข้อมูลว่างเปล่า
    *   **การ์ดผลงานแต่ละใบ** จะแสดงรูป **ดินสอ (แก้ไขข้อมูล)** และ **ถังขยะ (ลบข้อมูล)** ขึ้นมาที่บริเวณมุมขวาบนของการ์ด
    *   **การปรับแต่งตำแหน่ง**: ให้นำเมาส์ไปวางที่ด้านบนสุดของการ์ดผลงานจนขึ้นแถบลากวาง (Grip) จากนั้นลากและปล่อยสลับการ์ดในตำแหน่งที่ต้องการได้ทันที
5.  เมื่อทำการอัปเดตข้อมูลเสร็จสิ้นแล้ว ให้คลิกปุ่ม **"Lock" (รูปแม่กุญแจปลดล็อกสีแดง)** อีกครั้งเพื่อปิดโหมดแก้ไขข้อมูลและเปลี่ยนเข้าสู่โหมดการแสดงผลปกติ ป้องกันผู้อื่นกดเข้ามาแก้ไขผลงานของคุณโดยไม่ได้รับอนุญาต
